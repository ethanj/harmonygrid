THE MIDI CONNECTION 
The GR-50 also presents a full comple¬ 
ment of MIDI features. Both poly mode 
and mono mode (i.e., one MIDI chan¬ 
nel to each string) are supported. If you 
have the channels available, mono 
mode best captures the nuances of play¬ 
ing individual string bends, chokes, and 
other effects. Mono also allows different 
sounds to be allocated to different 
strings if you use external sound 
module(s). 
The GR-50 sends pitch bend mes¬ 
sages—continuous or chromatic (dis¬ 
crete steps)—to indicate string bend. 
Being in poly mode and bending more 
than one string automatically selects 
chromatic mode. A branch structure 
enables the same signal to be sent with 
two different sets of MIDI parameters at 
the same time (for instance, poly mode 
data over MIDI channel 3, and mono
