Once you get used to reading the 4x3 
grid, you can read the interval pattern 
(up one minor third, right one major

from the patterns produced by other 
chord types. The 4x3 grid is useful for 
representing chords built on thirds (see 
Hs-4) , and is used extensively in the Har¬ 
mony Grid manual and reference cards. 
This chord-building capability expands 
the possibilities for improvising. One 
might, for example, select a chord type 
and trigger chords by playing single 
notes on a MIDI keyboard, while soloing 
on the grid with the mouse.
