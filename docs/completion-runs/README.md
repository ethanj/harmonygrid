# Completion evidence

See [the review guide](../review-guide.md) for scope, defaults, commands, and limits. Reports named `browser-check.json` are the latest completed runs; their `checks` entries record individual assertions. Screenshots show production UI unless located under `docs/prototypes`.

The normal and expanded browser endurance runs contain more than 1,000 draw samples each, but run for only one minute. The retained run contains fewer than 1,000 samples. Neither these diagnostic runs nor accelerated musical-time simulation certify physical latency or the longer scored acceptance plan.

The slot-editor regression initially exposed a footer overflow after adding pitch recollection. Its production layout now scrolls content while keeping the footer visible, and all 30 slot assertions pass. An isolated OPFS save exceeded the harness's original five-second wait; the browser file-operation wait was extended to ten seconds, and the full isolated run passed. File failures and preservation behavior are separately covered by the document harness.
